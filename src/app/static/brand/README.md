# Логотип

Положите сюда официальный логотип Альфа-Будущее из материалов организаторов:

- `logo.svg` — лучше всего, или
- `logo.png` — высота от 64 px, прозрачный фон.

Шапка всех страниц подхватит файл сам. Пока файла нет, в шапке только название кабинета.
Логотип в репозиторий мы не рисовали и не копировали: его нужно взять у организаторов.
